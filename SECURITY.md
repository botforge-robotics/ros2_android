# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x (Jazzy) | :white_check_mark: |
| < 1.0.0 (Legacy Humble) | :x: |

---

## Reporting a Vulnerability

The Rosdroid team takes security issues seriously. If you discover a vulnerability, please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Send an email to [security@botforge.org](mailto:security@botforge.org) or [opensource@botforge.org](mailto:opensource@botforge.org).
3. Include detailed information:
   - Type of vulnerability (e.g. PRoot sandbox escape, privilege escalation, unauthenticated socket injection)
   - Step-by-step reproduction instructions or proof-of-concept
   - Impact assessment
   - Suggested fix (if available)

### Response Timeline
- **Initial Response**: Within 48 hours acknowledging receipt.
- **Triage & Status Update**: Within 7 business days with an assessment and remediation timeline.
- **Disclosure**: Coordinated public release once a fix or workaround is available.
